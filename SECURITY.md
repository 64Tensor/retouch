# Security

Please don't report security problems in public issues.

Report them privately, through GitHub's
[private vulnerability reporting](https://github.com/64Tensor/retouch/security/advisories/new),
or by email to contact@64tensor.com. Say which version you tested, what you found, and how to
reproduce it. You'll get an answer within a few working days, and a fix is released, with credit
to you if you want it, before the problem is described in public.

Fixes go into the latest release only. Rétouch runs entirely in the browser, so the reports that
matter most are about what a crafted image, video or metadata block can make the editor do, and
about the ML package's downloads.
